\# Student Performance Analysis \& Prediction



A machine learning project built in Python to analyze key factors affecting student academic performance and predict final test scores.



\## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) and builds machine learning regression models to evaluate student performance based on features such as study hours and attendance rates.



\## 📁 Repository Structure

\- `Python script.ipynb`: Complete Jupyter Notebook with data processing, visualization, and modeling.

\- `student\_performance.csv`: Dataset containing student records and exam scores.

\- `student\_model.joblib`: Trained machine learning model saved with `joblib`.

\- `README.md`: Project documentation and setup guide.



\## 🛠️ Tech Stack \& Libraries

\- \*\*Language:\*\* Python 3.13

\- \*\*Environment:\*\* Jupyter Notebook

\- \*\*Libraries:\*\* Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn, Joblib



\## 📊 Key Findings \& Results

\- \*\*Exploratory Data Analysis:\*\* Strong positive correlation observed between study hours, attendance, and final scores.

\- \*\*Model Performance:\*\* Random Forest and Linear Regression models were trained to accurately predict student scores based on daily academic habits.
