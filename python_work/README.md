# ?? Study Habits Survey: Data Exploration & Analysis

## ?? Overview
This project presents an exploratory data analysis (EDA) of a simulated survey focusing on student study habits. The analysis investigates relationships between student study hours, phone usage, sleep schedules, commutes, and academic performance (GPA).

---

## ?? Project Structure
- python_work/
  - Nahayo_Jean_de_Dieu_Study_Habits (1).ipynb: Main Jupyter Notebook containing data exploration and analysis.
  - Nahayo_Jean_de_Dieu_Study_Habits.ipynb - Colab.pdf: Exported PDF report.
  - study_habits_survey.csv: The underlying dataset.

---

## ?? Dataset Information
- **Sample Size:** 80 students
- **Attributes:** 9 columns (student demographics, academic metrics, lifestyle habits)

---

## ?? Key Findings & Insights
- **Study Habits & GPA:** Moderate positive correlation ( \approx 0.57$) between weekly study hours and GPA.
- **Faculty Breakdown:** Engineering students study the most ($\sim14.9$ hrs/week); Education students average $\sim12.0$ hrs/week.
- **Screen Time Impact:** ~30% of students use phones >5 hours/day, showing a weak negative correlation with GPA ( \approx -0.26$).
